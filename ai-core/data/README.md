# Datasetlar papkasi (Data Directory)

Ushbu papkaga istalgan `.json` formatdagi FAQ datasetingizni tashlashingiz mumkin.
Tizim avtomatik ravishda ushbu papkadagi `.json` faylni topadi va ChromaDB ga o'qitadi.

Agar faylni almashtirsangiz yoki yangilasangiz:
1. Server avtomatik ravishda fayl o'zgarganini (MD5 hash orqali) sezadi.
2. Eski ma'lumotlarni tozalab, yangi savol-javoblarni ChromaDB ga yuklaydi.
